## Rationale

**AIR-055:** The blanket “before any write” clause conflicts with independent raw capture; the exception must be destination-specific. `docs/spec/REQUIREMENTS.md:65`; `evidence/host.c:243`.

**AIR-062:** Normal-log location and diagnostic app-data location need distinct scopes. `docs/spec/REQUIREMENTS.md:72`; `docs/spec/DECISIONS.md:206`.

**AIR-072:** Today every callback record enters the ring before Java can inspect it. `evidence/host.c:245`; `docs/design/S3_RECEIVER.md:233`.

**AIR-073:** OD-198 explicitly accepts names and addresses, but does not explicitly waive the other sensitive categories. P2 preserves those prohibitions pending owner review. `docs/spec/DECISIONS.md:206`; `docs/spec/REQUIREMENTS.md:83`.

**AIR-083:** The identity-key prohibition predates diagnostics and has no OD-198 exception. Existing recursive app-data and descriptor listings threaten filename secrecy. `docs/spec/DECISIONS.md:178`; `tools/unit-probes/parkcast-diag/parkcast_diag.sh:65`; `:81`.

**AIR-084:** A version suffix identifies the build through the existing marker without changing OD-178’s grammar. Native build configuration must agree with APK metadata. `docs/spec/DECISIONS.md:186`; `docs/design/S3_RECEIVER.md:241`.

**AIR-085:** The ring sanitizes and truncates text before delivery; raw capture must precede that transformation. `evidence/ring.c:66`; `:106`.

**AIR-086:** Capacity drops already have separate native counters, including control drops. Video callbacks can return before enqueueing any AU or configuration. `evidence/ring.c:122`; `evidence/host.c:157`.

**AIR-087:** OD-198 specifies no cap or retention policy; bounded single-file truncation is proposed, not inferred. `docs/spec/DECISIONS.md:206`.

**AIR-088:** Diagnostics must remain observational; the unresolved upstream failure must not become a new gate dependency. `docs/evidence/S3_FIRST_RUN_FINDINGS.md:23`; `docs/design/S3_RECEIVER.md:365`.

**AIR-089:** The current tool copies normal logs, auto-launches the app and temporarily captures all logcat. Those paths require revision for the requested read-only collection and key secrecy. `tools/unit-probes/parkcast-diag/parkcast_diag.sh:87`; `:92`; `:122`.
