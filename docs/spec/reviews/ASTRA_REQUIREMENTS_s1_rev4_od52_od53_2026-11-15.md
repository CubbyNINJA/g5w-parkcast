## Rationale

**AIR-007:** OD-52 supplies the missing 1 s limit and requires an inter-check termination case (`docs/spec/DECISIONS.md:60`; `docs/spec/AMBIGUITY_REGISTER.md:40`). Measuring from the input event to process exit prevents detection delay or stop latency from escaping the assertion. The existing `ended_at` denotes when the runner decided to end, so it alone cannot prove this interval (`docs/spec/S1_INTERFACES.md:87`). This closes review finding 4 (`docs/spec/reviews/ASTRA_REVIEW_s1_od50_2026-11-15.md:28`).

**AIR-031:** The precedence pointer preserves the existing ending codes while making record-write failure decisive, including retained exit 130 for interruption (`docs/spec/DECISIONS.md:61`; `docs/spec/REQUIREMENTS.md:41`). It resolves the conflict identified in finding 5 without changing successful-run verdict semantics (`docs/spec/reviews/ASTRA_REVIEW_s1_od50_2026-11-15.md:29`).

**AIR-033:** Clause (e) reproduces the adopted review wording (`docs/spec/reviews/ASTRA_REVIEW_s1_od50_2026-11-15.md:95`; `docs/spec/DECISIONS.md:61`). The tests observe downstream invocations as well as outputs, so an erroneous continuation cannot pass merely because a later step also fails. Existing reminder and owner-handled-record behavior remains intact (`docs/spec/REQUIREMENTS.md:43`). Evidence tiers retain their existing limits (`specs/README.md:34`).
